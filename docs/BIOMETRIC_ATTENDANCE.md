# دليل ربط وتشغيل أجهزة البصمة والحضور الذكي في نظام Orqiva

يوفر نظام **أوركيفا (Orqiva)** دعماً هندسياً متكاملاً لأجهزة البصمة والحضور والانصراف البيومترية بمختلف أنواعها وطرزها (بصمة الإصبع، بصمة الوجه، كارت RFID، وكلمة المرور)، مع تركيز خاص على أجهزة **ZKTeco** الأكثر انتشاراً في مصر والشرق الأوسط، بالإضافة إلى أي جهاز يدعم بروتوكول **ADMS** أو بروتوكولات الدفع المباشر عبر HTTP.

---

## 1. طرق الربط المدعومة

يدعم النظام 4 طرق ربط مرنة تناسب كافة السيناريوهات التشغيلية للفروع:

```

       ▼                            ▼                           ▼
[1. خادم ADMS المباشر]    [2. سكريبت الشبكة المحلية]    [3. فلاشة USB]
```

### الطريقة الأولى: الربط المباشر التلقائي عبر ZKTeco ADMS (الخادم السحابي) ⭐ الموصى بها

يقوم جهاز البصمة بدفع حركات الحضور في نفس اللحظة عبر الإنترنت أو الشبكة المحلية مباشرة إلى خادم أوركيفا بدون الحاجة لأي برامج وسيطة مفتوحة.

#### الإعداد في جهاز البصمة (شاشة الجهاز):
1. اضغط على زر **القائمة (Menu / M/OK)** في جهاز البصمة.
2. انتقل إلى: **الاتصال (Comm.)** &larr; **إعدادات خادم السحابة (Cloud Server / ADMS)**.
3. اضبط القيم التالية:
   - **تمكين خادم السحابة (Enable Cloud Server):** نعم (Yes).
   - **عنوان الخادم (Server Address):** رابط السيرفر (مثال: `192.168.1.50` في الشبكة المحلية، أو الدومين الخاص بك `erp.company.com`).
   - **منفذ الخادم (Server Port):** `3000` (أو منفذ الويب النشط `80` / `443`).
   - **تفعيل اسم النطاق (Enable Domain Name):** نعم إذا كنت تستخدم دومين، لا إذا كان IP رقمي.
   - **الخادم الوكيل (Proxy Server):** معطّل (No).
4. احفظ الإعدادات وأعد تشغيل الجهاز أو اضغط اتصال.
5. في نظام أوركيفا (صفحة **أجهزة الحضور والبصمة**):
   - اضغط **جهاز جديد**.
   - أدخل اسم الجهاز وفرعه، وضع **الرقم التسلسلي (Serial Number)** المطابق تماماً للرقم المكتوب على ملصق ظهر الجهاز (مثال: `ZK-MAIN-001`).
   - بمجرد اتصال الجهاز، سيتعرف عليه مسار `/iclock/cdata` تلقائياً، وسيتم تجميع البصمات في سجل الحضور فوراً!

### الطريقة الثانية: المزامنة عبر الشبكة المحلية (Local IP Bridge)

إذا كان جهاز البصمة موصولاً بكابل شبكة LAN داخل الفرع وله IP محلي (مثلاً `192.168.1.201:4370`):

1. **اختبار الاتصال بالجهاز:**
   ```bash
   npm run attendance:sync -- --test --ip=192.168.1.201 --port=4370
   ```

2. **سحب ومزامنة الحضور مباشرة:**
   ```bash
   npm run attendance:sync -- --file=attlog.dat --sn=ZK-MAIN-001 --url=http://localhost:3000
   ```

3. يمكن جدولة هذا الأمر في Cron Job أو Windows Task Scheduler ليعمل دورياً كل ساعة أو عند نهاية وردية العمل.

---

### الطريقة الثالثة: استيراد ملف الفلاشة USB (بدون شبكة)

مناسبة للمواقع المعزولة أو الفروع التي لا يتوفر بها كابل شبكة:

1. ضع فلاش ميموري (USB) في منفذ جهاز البصمة.
2. من قائمة الجهاز ادخل على: **إدارة USB &larr; تنزيل بيانات الحضور (Download Attlog)**.
3. سيتم حفظ ملف باسم `attlog.dat` أو `1_attlog.dat`.
4. افتح نظام أوركيفا &larr; **أجهزة الحضور والبصمة** &larr; تبويب **«استيراد ملف»**.
5. اختر الجهاز والفرع وارفع الملف مباشرة؛ يدعم النظام الملفات النصية، الفواصل التلقائية (Tab, Comma, Spaces) ويقوم بمعالجتها في أجزاء من الثانية.

---

### الطريقة الرابعة: الربط البرمجي عبر الـ API (REST Webhook)

للأنظمة الخارجية، تطبيقات الهاتف، أو أجهزة البوابات الذكية:

- **الرابط:** `POST /api/attendance-devices/ingest`
- **الترويسة (Header):** `X-Device-Key: <مفتاح API الخاص بالجهاز>`
- **نوع المحتوى:** `application/json`

**مثال الحمولة (Payload):**
```json
{
  "punches": [
    {
      "device_user_id": "101",
      "punched_at": "2026-10-26 08:58:30",
      "punch_type": "IN",
      "verify_mode": "FINGERPRINT"
    },
    {
      "device_user_id": "101",
      "punched_at": "2026-10-26 17:05:12",
      "punch_type": "OUT",
      "verify_mode": "FINGERPRINT"
    }
  ]
}
```

## 2. كيفية ربط أرقام المستخدمين بالموظفين (Device User Mappings)

1. في جهاز البصمة، يكون لكل موظف رقم معرّف (User ID / PIN)، مثل `1`, `2`, `105`.
2. في أوركيفا، افتح تبويب **«ارتباط الموظفين»** داخل الجهاز.
3. يمكنك ربط كل رقم مستخدم بالموظف المقابل له بالاسم وكود الموظف.
4. **الميزة الذكية:** إذا وصلت بصمات قبل إجراء الربط، يقوم النظام بحفظها كبصمات غير مربوطة (Unmapped)، وبمجرد أن تربط رقم المستخدم بالموظف، يقوم النظام فوراً وبأثر رجعي بربط كافة البصمات السابقة واحتساب الحضور والانصراف تلقائياً!

---

## 3. القواعد التشغيلية والسياسات

- **حماية التعديل اليدوي (Manual Override Protection):** إذا قام مسؤول الموارد البشرية بتعديل حضور يوم معين يدوياً (`source='MANUAL'`)، فإن المزامنة الآلية من جهاز البصمة لن تمس ذلك اليوم، صوناً لقرارات الإدارة.
- **منع التكرار (Deduplication):** البصمات المتكررة خلال ثوانٍ أو دقائق متقاربة تُقبل مرة واحدة فقط بناءً على قيد التفرد `(device_id, user_id, timestamp)`.
- **التوقيت الزمني والورديات:** يتم احتساب وقت الحضور والانصراف بتوقيت القاهرة الرسمي (`Africa/Cairo`) مع احتساب دقائق التأخير وساعات العمل الإضافي وفقاً لسياسة مواعيد الفرع وسماحية التأخير المسجلة في إعدادات الجهاز.
