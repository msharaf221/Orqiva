# Orqiva — أوركيفا ERP 🇪🇬

**المنظومة المؤسسية العربية السحابية لإدارة الحسابات العامة، المخزون، المبيعات والمشتريات، الموارد البشرية والرواتب، وإدارة علاقات العملاء.**

نظام متكامل صُمم وبُني ليناسب بيئة الأعمال والشركات التجارية والصناعية والخدمية في مصر والعالم العربي. يجمع بين قوة المحاسبة المزدوجة المتوافقة مع المعايير، ومرونة إدارة الفروع المتعددة، والدقة الضريبية المصرية، والتحكم المطلق في تخصيص واجهات العمل ومطبوعات الفواتير.

## 🚀 المزايا والقدرات الجوهرية

- **واجهة مستخدم عربية (RTL-First)** مبنية بأعلى معايير تجربة الاستخدام السلسة، مع خطوط محلية مدمجة وبحث عالمي ذكي `Ctrl + K`.
- **نظام محاسبي ذو قيد مزدوج حقيقي (Double-Entry Bookkeeping)** مع شجرة حسابات هرمية قياسية وتقارير مالية ختامية لحظية.
- **تخصيص كامل للمطبوعات والنوافذ:** إمكانية تكبير وتصغير النوافذ لمقاسات متعددة، ومحرك تصميم فواتير متقدم بـ 4 قوالب وألوان مخصصة وبطاقة تحويلات بنكية وشعار الشركة.
- **امتثال ضريبي ومحاسبي كامل لمصر:** دعم ضريبة القيمة المضافة (14%)، ضريبة كسب العمل التدريجية، التأمينات الاجتماعية بسقف 2026، وصندوق الشهداء (0.05%).
- **أمان وموثوقية عالية:** حماية من الطلبات المتزامنة بمفاتيح عدم التكرار (Idempotency Keys)، عزل صلاحيات على مستوى الدور والفرع (RBAC)، وجلسات HTTP-only مشفرة.
- **استقلالية تامة (Zero External Runtime Dependencies):** يعمل النظام محلياً أو سحابياً بالكامل مع محرك SQLite المدمج في Node.js 22.

## 🏛️ الأعمدة والوحدات المتكاملة (ERP Modules)

### 1. المحاسبة العامة وشجرة الحسابات (General Ledger)
- **دليل الحسابات القياسي (Chart of Accounts):** هيكل هرمي متكامل من 5 مستويات يغطي الأصول، الخصوم، حقوق الملكية، الإيرادات، والمصروفات.
- **قيود اليومية الآلية واليدوية (Journal Entries):** تتولد القيود آلياً عند اعتماد الفواتير، سداد الدفعات، إثبات حركات المخزون، صرف الرواتب، وتسوية التكاليف.
- **القوائم المالية الختامية:**
  - **ميزان المراجعة (Trial Balance):** مجاميع وأرصدة ومطابقة الأطراف المدينة والدائنة.
  - **قائمة الدخل (Income Statement / P&L):** الإيرادات وتكلفة البضاعة المباعة ومجمل وصافي الربح.
  - **قائمة المركز المالي (Balance Sheet):** الموقف المالي وحقوق الملكية في أي لحظة زمنية.
  - **دفتر الأستاذ المساعد:** كشف حساب تفصيلي لأي حساب مالي مع رصيد تراكمي.
- **الفترات المحاسبية:** إغلاق شهري وسنوي يمنع التعديل على العمليات السابقة بعد إقفال الفترة.

### 2. إدارة الخزينة والبنوك والشيكات (Treasury & Cheques)
- **حسابات مالية متعددة:** إدارة الخزائن النقدية، الحسابات البنكية، والمحافظ الإلكترونية لكل فرع.
- **إدارة أوراق القبض والدفع (Cheques Cycle):**
  - تسجيل الشيكات الواردة من العملاء والشيكات الصادرة للموردين.
  - دورة حياة كاملة للشيك: `تحت التحصيل` ⬅️ `محصل` أو `مرتد` أو `ملغى`.
  - قيود محاسبية وسيطة تلقائية لحسابات الشيكات تحت التحصيل والشيكات الصادرة المعلقة.

### 3. المبيعات والمشتريات وعروض الأسعار (Sales & Purchases)
- **فواتير المبيعات والمشتريات:** مسودات تفاعلية، احتساب دقيق للضرائب والخصومات، وقيود فورية عند الاعتماد.
- **المرتجعات وإشعارات الدائن والمدين (Credit & Debit Notes):**
  - إرجاع كلي أو جزئي مرتبط برقم الفاتورة الأصلية.
  - إعادة احتساب رصيد العميل أو المورد وتكلفة المخزون بدقة تامة.
- **عروض الأسعار والفواتير الشكلية (Quotations & Proforma):**
  - إنشاء عروض أسعار محددة الصلاحية وإرسالها للعملاء.
  - تحويل عرض السعر إلى فاتورة مبيعات معتمدة بنقرة واحدة.
- **قوائم الأسعار المتعددة (Price Lists):**
  - أسعار مخصصة (جملة، تجزئة، كبار عملاء، موزعين).
  - تحديد هوامش ربح أو خصومات ثابتة على فئات معينة.

### 4. إدارة المخزون المتقدم وتواريخ الصلاحية (FEFO & Landed Costs)
- **تتبع الدفعات وتواريخ الانتهاء (Batches & FEFO):**
  - خروج البضاعة وفق أولوية الانتهاء أولاً يخرج أولاً (First-Expired, First-Out).
  - تنبيهات استباقية بالأصناف الوشيكة على الانتهاء لحماية رأس المال من التلف.
- **رسملة التكاليف الإضافية (Landed Costs):**
  - توزيع تكاليف الشحن، النقل، الجمارك، والمناولة على فواتير الشراء.
  - توزيع بالتكلفة أو بالكمية أو بالوزن مع تحديث فوري لمتوسط التكلفة المرجح (WAC) والقيد المزدوج.
- **التحويلات المخزنية بين الفروع:** دورة شحن واستلام وتتبع العجز في الطريق، مع اقتراحات آلية لإعادة التوزيع.

### 5. محرك تخصيص النوافذ والفواتير والمطبوعات (Customization Engine)
- **نظام النوافذ الموحد (Window & Modal System):**
  - مقاسات قياسية جاهزة: `sm` (تأكيدات سريعة)، `md` (استمارات عادية)، `lg` (بيانات متعددة)، `xl` (جداول ومرتجعات ومسارات صفقات)، `2xl`، و `full`.
  - إمكانية تكبير وتوسيع أي نافذة بكامل الشاشة والتصغير الفوري (`Maximize/Restore`).
  - رأس نافذة متطور يحمل أيقونة مميزة وأزرار إجراءات مخصصة وأشرطة تمرير محكمة.
- **محرك تصميم الفواتير والمطبوعات (Invoice Designer):**
  - **4 قوالب تصميمية احترافية:**
    1. **العصري (Modern):** تصميم أنيق متعدد البطاقات مع ترويسة ملونة متباينة.
    2. **الكلاسيكي (Classic Letterhead):** ترويسة رسمية للمؤسسات والشركات مع خطوط فاصلة راقية.
    3. **المقتصد والمبسط (Minimal):** تصميم عالي الوضوح موفر لحبر الطابعات ومناسب للطباعة السريعة.
    4. **المدمج عالي الكثافة (Compact Density):** نموذج مكثف يجمع أكبر قدر من الأصناف في صفحة A4 واحدة.
  - **تخصيص الهوية البصرية:** اختيار من باليتات ألوان جاهزة (نيلي، بحري، زمردي، رمادي، ياقوتي، بنفسجي) أو إدخال كود لون HEX مخصص.
  - **الشعار والموقع:** رفع رابط الشعار والتحكم في موضعه (يمين، وسط، يسار).
  - **تبديل العناصر:** تفعيل أو إخفاء باركود الوثيقة، رمز التحقق QR، توقيعات المحاسب والمستلم وختم المنشأة، بند حماية المستهلك (14 يوماً)، وعمود كود الصنف (SKU).
  - **بيانات التحويل البنكي:** إظهار بطاقة الحساب البنكي المعتمد (اسم البنك، اسم الحساب، ورقم الآيبان IBAN) على الفاتورة لسهولة تحويل العملاء.
  - **إيصال الكاشير الحراري (POS Thermal Receipt 80mm):** وضع توفير الورق المدمج (Eco-Mode) وخيار إظهار اسم الكاشير.
  - **معاينة حية ومزدوجة (Live Dual Preview):** معاينة تفاعلية في الوقت الفعلي لكل من فاتورة A4 وإيصال الكاشير الحراري 80mm قبل الحفظ.

### 6. الموارد البشرية والرواتب المصرية (HR & Egyptian Payroll)
- **مسير الرواتب الممتثل للقانون المصري:**
  - **التأمينات الاجتماعية:** احتساب حصة الموظف (11%) وحصة الشركة (18.75%) مع الالتزام بسقف الأجر التأميني المعتمد لعام 2026.
  - **ضريبة كسب العمل التدريجية:** احتساب تلقائي لشرائح الدخل التصاعدية بعد خصم الإعفاء الشخصي السنوي.
  - **صندوق تكريم الشهداء:** احتساب النسبة القانونية (0.05% من إجمالي الراتب).
- **العقود وملفات الموظفين:** تسجيل العقود، المرتب الأساسي والمتغير، البدلات، تاريخ التعيين، وفترة التجربة.
- **الحضور والانصراف والإضافي:** تسجيل الحضور، الغياب، التأخير، وساعات العمل الإضافية، وترحيلها آلياً للمسير.
- **إدارة الإجازات:** رصيد الإجازات السنوية والعارضة والمرضية، مع فحص آلي لمنع التداخل وتجاوز الرصيد.

### 7. إدارة علاقات العملاء ومسار الصفقات (Enterprise CRM)
- **لوحة كانبان الصفقات (Deals Kanban Board):**
  - مسار بيعي تفاعلي من 5 مراحل: `تواصل أولي` (10%) ⬅️ `تأهيل الفرصة` (30%) ⬅️ `تقديم عرض السعر` (60%) ⬅️ `المفاوضات النهائية` (80%) ⬅️ `صفقة رابحة / مغلقة` (100%).
- **إدارة الأنشطة والمتابعات (Sales Activities):**
  - جدولة المكالمات، الاجتماعات، المهام، وتسجيل رسائل البريد والملاحظات مع تاريخ استحقاق وتنبيهات.
- **التارجت والعمولات الشهرية:**
  - تحديد مستهدف مبيعات شهري ونسبة عمولة لكل مندوب مبيعات.
  - احتساب نسبة تحقيق التارجت وقيمة العمولة المستحقة آلياً من واقع الفواتير المحصلة، وربطها بمسير الرواتب.
- **التحويل السريع إلى دورة المبيعات:**
  - تحويل طرف الاتصال في الصفقة إلى عميل رسمي في النظام بنقرة واحدة.
  - توليد مسودة عرض سعر أو فاتورة مباشرة من بيانات الصفقة وقيمتها.

### 8. الفاتورة والإيصال الإلكتروني المصري (ETA Integration)
- **مواصفات الفاتورة الإلكترونية المصرية:**
  - توليد كود التحقق السريع TLV Base64 المعتمد من مصلحة الضرائب المصرية بمحددات الوسوم الخمسة (الاسم، المسجل الضريبي، التوقيت، الإجمالي، والضريبة).
  - جاهزية الربط ببيئة مصلحة الضرائب المصرية (UBL 2.1 / JSON Invoice).
  - تتبع حالة المستندات الإلكترونية وأكواد الرفض والقبول في لوحة إعدادات الفاتورة الإلكترونية.

### 9. الفروع المتعددة وحسابات الملاك والتوزيعات (Multi-Branch & Owners)
- **إدارة الفروع المتعددة:** كل فرع له استقلالية تامة في المخزون وترقيم الفواتير والموظفين المخصصين.
- **المصروفات المشتركة:** توزيع المصروفات المركزية بالتساوي أو بنسبة مبيعات كل فرع باستخدام خوارزمية أكبر البواقي (Largest Remainder) لضمان دقة القروش.
- **لوحة المجموعة الموحدة:** مقارنة أداء الفروع جنباً إلى جنب مع مصفوفة جرد موحدة لجميع الفروع.
- **حسابات الملاك وتوزيع الأرباح:** إدارة نسب الشركاء وحساب صافي الأرباح القابلة للتوزيع بعد اقتطاع الاحتياطي، مع منع صرف أي توزيع يتجاوز السيولة المتاحة فعلياً.

## ⚡ التشغيل السريع والإعداد (Getting Started)

### المتطلبات الأساسية
- **Node.js 22.13 أو أحدث** (تم الاختبار والتأكيد على `22.22.3`).
- مدير حزم `npm`.

### خطوات التثبيت والتشغيل المحلي

1. **استنساخ المستودع وتثبيت الاعتماديات:**
   ```bash
   git clone <repo-url>
   cd Orqiva
   npm ci
   ```

2. **ضبط متغيرات البيئة:**
   ```bash
   cp .env.example .env
   # افتح ملف .env وعدل SEED_PASSWORD إلى كلمة مرور قوية (10 أحرف على الأقل)
   ```

3. **تهيئة قاعدة البيانات وتطبيق الترحيلات:**
   ```bash
   npm run setup
   ```

4. **بدء خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:5173`

5. **بيانات الدخول الافتراضية:**
   - **البريد الإلكتروني:** `admin@orqiva.com`
   - **كلمة المرور:** القيمة المحددة في `SEED_PASSWORD` داخل ملف `.env`.

## 🧪 أوامر الفحص والاختبارات (Testing & QA)

يتضمن النظام منظومة اختبارات صارمة وشاملة تغطي كافة العمليات الحسابية والمالية والأمنية:

```bash
# تشغيل جميع اختبارات الـ API والتكامل (245 اختبار في 31 ملف اختبار):
npm test

# فحص توافق أنواع TypeScript بدقة صارمة:
npm run typecheck

# فحص وتطبيق تنسيق الأكواد (Prettier):
npm run format:check
npm run format

# بناء النسخة الإنتاجية المجمعة:
npm run build

# تشغيل اختبارات المتصفح الشاملة (E2E Playwright):
npm run test:e2e
```

## 💾 النسخ الاحتياطي واستعادة البيانات (Backup & Restore)

يستخدم النظام تقنية **SQLite Online Backup API** لأخذ نسخ احتياطية متسقة لحظياً دون الحاجة لإيقاف الخادم:

```bash
# أخذ نسخة احتياطية فورية:
npm run backup

# أو تحديد مسار مخصص للنسخة:
npm run backup -- backups/daily-backup.db
```

### استعادة وصول المدير في حالات الطوارئ:
في حال فقدان كلمة مرور الحساب الإداري، يمكن تشغيل الأمر التالي من سطر أوامر السيرفر:
```bash
ADMIN_EMAIL=admin@orqiva.com ADMIN_PASSWORD=NewStrongPassword123 npm run admin:reset
```
